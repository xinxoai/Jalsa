# Jalsa

Jalsa ("a sitting" in Arabic) is a 2D web game prototype in which users create AI friends, choose a setting, invite friends to sit with them, and chat.

It accompanies the research proposal *Do We Become Our AI Friends? A Proposed Randomised Controlled Trial* (Dana Househ).

## Features

- Character creator: appearance (skin, hair or hijab, outfit, extras), name, field, up to three personality traits, backstory
- Settings: garden, café, rooftop
- Invite one or more friends to a sitting
- One-to-one or group chat; replies generated by a large language model, in Arabic or English

## Running it

Open `index.html` in a browser. The character creator and settings work offline. AI replies require the hosted version of the prototype; offline, the chat shows a notice instead of replies.

## Status

Research prototype. Not a clinical tool. Friends are saved only in the browser.
